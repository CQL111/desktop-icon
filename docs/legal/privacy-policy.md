# 隐私政策

**最后更新：2026-11-13**
**适用产品：今日运势 · 桌面桌宠（以下简称"本应用"）**
**开发者：CQL111（以下简称"我们"）**

我们尽量少收集数据。本应用的核心功能（黄历、抽签、运势卡片、桌宠）**完全离线运行**，不联网也能使用。

---

## 一、我们收集哪些数据

### 1. 仅保存在你本机、不上传的数据

| 数据 | 用途 | 存放位置 |
|---|---|---|
| 桌宠位置、形象偏好、动画开关 | 记住你的使用习惯 | 本机配置文件 |
| 生日、性别（可选） | 生成个人运势、八字/星座解读 | 本机配置文件 |
| 抽签历史、运势缓存 | 当天结果保持一致、连续天数统计 | 本机配置文件 |
| 运势精灵加持值 | 记录摆位与祈福结果 | 本机配置文件 |
| 对话记录（最近若干轮） | 支持连续追问 | 本机配置文件 |
| API Key（你填写的） | 调用 AI 服务 | 本机配置文件 |
| 日志文件 | 排查故障 | 本机日志目录 |

这些数据**不会发送到我们的服务器**——我们也没有服务器。删除应用或在设置中清除对应内容即可移除。

### 2. 在你使用 AI 功能时会发送给第三方的数据

只有当你**主动提问**或**卡片展示 AI 解读**时，才会发生网络请求：

| 发送内容 | 接收方 | 目的 |
|---|---|---|
| 你的问题、当天的运势数据、生日推导出的生肖/星座、当前时辰、对话上下文（最近几轮） | 你在设置中选择的 AI 服务（默认 DeepSeek） | 生成解读与回答 |
| 典籍检索命中的原文片段（本地检索，只发送命中的段落） | 同上 | 让回答有据可查 |

我们**不会**发送：真实姓名、手机号、身份证、精确地址、设备标识、通讯录、文件内容、屏幕截图。

> AI 服务提供方会按其自身隐私政策处理这些数据（DeepSeek 隐私政策见其官网）。如果你不希望任何数据离开本机，可以：
> - 关闭 AI 功能（不配置 Key），本应用仍可正常抽签、看黄历
> - 改用本机 Ollama 模型（设置 → 本地模型），此时数据不出本机

### 3. 安装包内置的体验 Key

部分版本（个人体验版）内置了一个低额度 API Key，仅用于让你开箱试用 AI 功能。使用内置 Key 时，你的提问同样会发送给 AI 服务提供方。你可以在设置里换成自己的 Key，或清除内置 Key。

---

## 二、我们不收集什么

- 不收集设备指纹、IMEI、MAC 地址、IP 之外的任何标识
- 不收集通讯录、短信、照片、文件、剪贴板
- 不做后台截屏、不做键盘记录
- 不向我们自己的服务器上报任何统计（无埋点、无遥测）
- 不出售、不出租、不共享任何数据（因为我们不持有这些数据）

---

## 三、数据存储位置与保留期限

所有本机数据位于：

- **Windows**：`%APPDATA%\fortune-ball\`
- **macOS**：`~/Library/Application Support/fortune-ball/`

日志文件默认保留最近 10 个（每个最大 5MB），按日期轮转。你可以随时在托盘菜单「打开日志文件夹」查看，或「清空日志」。

---

## 四、你的权利

| 权利 | 怎么做 |
|---|---|
| 查看本机保存的数据 | 打开上面的目录，`config.json` 为明文 JSON |
| 删除全部数据 | 卸载应用后手动删除该目录，或在设置中逐项清除 |
| 撤回 AI 授权 | 设置 → 线上模型 → 清除已存 Key |
| 不使用 AI | 不配置任何 Key 即可，其余功能正常 |
| 删除对话记录 | AI 对话窗口 →「新对话」 |
| 关闭日志 | 托盘 → 日志级别 → 选择更高等级 |

## 五、儿童

本应用不面向 14 岁以下儿童。若你是未成年人，请在监护人指导下使用。

---

## 六、数据安全

- API Key 保存在本机配置文件中，不上传
- 日志写入时自动对 `token`、`password` 等字段打码
- 与 AI 服务之间使用 HTTPS 传输
- 应用不监听端口，不接受远程连接

请注意：本机配置文件为明文。如果多人共用一台电脑，建议不要在应用内保存他人可见的 Key。
