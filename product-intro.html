01 · 产品定位

把「今天运气怎么样」
变成桌角的一秒钟

它不是一个需要专门打开的应用，而是一枚长在桌面上的小球：平时安静，想用时伸手就能碰到。

01

轻

全屏透明窗口 + 点击穿透，球之外的一切鼠标事件都直接交给桌面；球的位置会被记住，下次开机还在原地。

点击穿透位置记忆托盘常驻
02

快

鼠标移上去浮出四个签，点一下直接弹卡。没有启动页、没有登录、没有广告，结果就在一秒钟之内。

hover 四签点签即出失焦收起
03

懂你

右键打开 AI 对话，Agent 按问题自动查黄历、时辰、命理；结合生日与精灵加持，给出属于你自己的解读。

多轮对话工具调用个性化
它解决的未必是「算命」，而是每天随时可能冒出来的那一点点——想要确定感。
02 · 为什么

运势，不该占用一整个 App

大多数运势产品把「看一眼今天」做成了完整的产品旅程。我们希望把它还原成一个动作。

传统运势产品≈ 1–2 分钟
  1. 1打开 App 或网页
  2. 2经过首页推荐、广告或登录
  3. 3选择「今日运势」再抽签
  4. 4读一段对所有人都一样的文案
结果通常与「我」无关，也很难想再看第二次。
今日运势 · 桌面悬浮球≈ 1 秒
  1. 1hover 悬浮球，四个签浮现
  2. 2点一个签，运势卡片直接弹出
  3. 3黄历 · 评分 · 个人 · 精灵加持同屏
  4. 4想问更多，右键继续对话
不打断手上的事，用完即走。

04 · 功能

四个签，回答四个问题

此刻、今天、我自己、我的运气——四类信息各有自己的生成逻辑，但都收在同一张卡片语言里。

⏰此刻

此刻个人运势

「现在适合做什么？」

十二时辰的吉言与提点，叠加当下宜忌；填过生日会附加一条属于你的个人摘要。

📅今日

今日黄历

「今天是什么日子？」

干支年与生肖、宜忌清单、幸运色与幸运数字，再加上今日运势评分和风格文案。

👤个人

今日个人运势

「我今天怎么样？」

从生日推导生肖、星座、八字与五行方位，可在综合命理 / 八字排盘 / 星座性格间切换。

🔮精灵

精灵祈福

「我想再加点运气。」

打开运势精灵面板：查看五项加持、当前方位与今日祈福次数，把运气一点点攒起来。

05 · AI

不是聊天框，是一个会「查资料」的 Agent

右键球打开对话窗。问题进来先选工具，拿到真实测算结果再组织答案——而不是凭空生成。

AI 运势对话多轮 · 工具调用 · 可中断
这周哪天适合签合同？
🛠 查阅黄历🛠 测算时段
周三（11/12）干支为乙巳日，宜「签约、会谈」，是本周最适合落笔的一天。（示意）
那财运呢？顺手帮我祈福。
🛠 查看精灵🛠 祈福
内置 7 个工具，Agent 自己决定调哪个
  • get_almanac按日期生成黄历、宜忌、幸运色
  • get_hour_fortune此刻时辰吉言 + 个人摘要
  • get_today_fortune今日运势，五种风格可选
  • get_personal_chart综合 / 八字 / 星座命理档案
  • get_range_fortune明日与本周运势
  • get_spirit_status五项加持与今日祈福余量
  • bless_spirit明确要求时为维度祈福 +1
➕ 场景注册表：像「按生日分组」这类临时业务，可以动态挂载额外工具，核心代码一行不动。
06 · 运势精灵

把「风水摆位」变成看得见的加成

它不是一只需要投喂的宠物，而是一台运势维度加持器：把球停在对应的方位，或者主动祈福。

水综合左上
木事业右上
金财运左下
火爱情桃花
土健康中央
五行 ↔ 方位 ↔ 运势维度：球停在哪，就在补哪一项
1
摆位加持

球在同一方位停留约 5 分钟，对应维度自动 +1，单项凭摆位最多累积到 2。

2
主动祈福

在精灵面板指定维度 +1，每天 3 次；单项总上限为 3，跨日自动重置。

3
测运时生效

抽签时把加持作为常量叠加到维度分数，并自动兼容「爱情 / 感情」两种字段名。

09 · 工程

离线优先，失败静默，出问题会自己诊断

AI 是增强项，不是前置条件——没有网络、没有 Key，内置的黄历与抽签依然完整可用。

🧠

模型可选

线上默认 DeepSeek，兼容任意 OpenAI 协议的 Chat Completions 端点；本机装了 Ollama 时优先走本地模型，数据不出机器。

🔒

隐私边界

API Key 只存在本机 %APPDATA%/fortune-ball/config.json，界面只显示打码片段；源码与 git 仓库不含密钥，日志自动打码 token。

🩺

自愈链路

结构化日志（5MB × 10 轮转）→ watcher 捕获错误 → detector 分类 → AI 诊断并系统通知；启动时还会跑 7 项自检。

托盘常驻 开机自启（安装包模式） Ctrl + Alt + F 全局抽签 卡片失焦自动收起 AI 失败静默降级 今日 / 明日 / 本周缓存
10 · 下一步

接下来的五个方向

从「看运势」走向「调运势」：让位置、信息与诉求都成为可用的输入。

01
位置即运势

球放在哪，就补哪一项；可配置「位置 → 提升维度」的映射。

02
多信息推断

从单一日期推算，扩展到生日、性别、位置等多源信息的综合推断。

03
诉求驱动建议

说出你的诉求，由 Agent 给出可执行的调整方案，而不只是一段解读。

04
天气与地理

接入天气和城市位置，让黄历与提示更贴近你所在的地方。

05
分类提升 / 一键提升

按维度逐项提升，也支持一次性把好运拉满。
